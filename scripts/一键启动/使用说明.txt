================================================================
  Jarvis AI - 一键启动脚本使用说明（4 个版本）
================================================================

不知道选哪个？看这里：
┌──────────────────────────────────────────────────────────┐
│  我的电脑是 Win10/Win11              → 用「3_通用版」     │
│  我的电脑是 Win7 老笔记本            → 用「1_Win7版」     │
│  我想用手机在外面 4G/5G 访问贾维斯    → 用「4_手机远程版」 │
│  我搞不清系统版本                    → 用「3_通用版」     │
└──────────────────────────────────────────────────────────┘


================================================================
  1_Win7版_start_jarvis.bat  —  Windows 7 专用
================================================================
适合：Win7 老笔记本、低配机器、Python 3.8.10

特点：
  * 全英文界面（避免 Win7 GBK 编码乱码）
  * 自动跳过向量库（chromadb 不支持 Win7）
  * 用 requirements-win7.txt 锁定兼容版本
  * 自动检测 Python 3.8.x

前置条件：
  * 已安装 Python 3.8.10（唯一支持 Win7 的版本）
    下载：https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe
    安装时务必勾选 "Add Python to PATH"


================================================================
  2_Win10版_start_jarvis.bat  —  Windows 10/11 专用
================================================================
适合：Win10、Win11、现代电脑、Python 3.10+

特点：
  * 中文界面（UTF-8 编码）
  * 完整依赖（含向量库 chromadb，记忆检索更准）
  * 支持 PowerShell 现代特性
  * 自动打开浏览器 + 自动日志

前置条件：
  * 已安装 Python 3.10 或更高版本
    下载：https://www.python.org/downloads/
    安装时勾选 "Add Python to PATH"


================================================================
  3_通用版_start_jarvis.bat  —  自动识别系统（推荐！）
================================================================
适合：所有 Windows 系统（自动判断 Win7/Win10/Win11）

特点：
  * 自动检测 Windows 版本
  * Win7 → 走简化路径（无向量库）
  * Win10+ → 走完整路径（含向量库）
  * 自动检测 Python 版本是否兼容
  * 一个脚本通吃所有系统

这个脚本最省心，不知道选哪个就用这个。


================================================================
  4_手机远程版_start_jarvis.bat  —  手机 4G/5G 远程访问
================================================================
适合：在外面用手机访问家里电脑上的贾维斯

特点：
  * 启动后端服务
  * 自动启动 Cloudflare Tunnel（免费公网地址）
  * 显示二维码 + URL，手机扫码即用
  * 不需要公网 IP、不需要端口映射、不需要域名

前置条件：
  * 已下载 cloudflared.exe 放到本目录，或已加入 PATH
    下载：https://github.com/cloudflare/cloudflared/releases/latest
    Win7 用 2023.8.2 版本（最后一个支持 Win7 的）
    Win10+ 用最新版即可

使用流程：
  1. 双击运行此脚本
  2. 等待出现 https://xxx-xxx.trycloudflare.com 地址
  3. 手机扫码或手动输入地址访问
  4. 关闭窗口即断开（地址会变，下次重新生成）


================================================================
  通用准备工作（所有版本都要做）
================================================================
1. 把整个 kizuna-ai 文件夹解压到电脑任意位置
   （路径最好不要有中文，比如 D:\kizuna-ai）

2. 第一次启动会自动创建 backend\.env 配置文件
   启动后浏览器打开 → 进入「设置」页 → 填写大模型 API Key
   推荐 智谱GLM（有免费额度）：https://open.bigmodel.cn/

3. 第一次启动会自动安装依赖（约 3~15 分钟）
   Win7 较慢，Win10+ 较快，请耐心等待

4. 想要桌面快捷方式？回到项目根目录双击 install_shortcut.bat


================================================================
  常见问题
================================================================
Q: 启动后浏览器打不开？
A: 检查防火墙是否放行 8000 端口。Win7 用：
   netsh advfirewall firewall add rule name=Jarvis8000 dir=in action=allow protocol=TCP localport=8000

Q: 依赖安装失败？
A: 重新双击脚本再跑一次。90% 是网络问题。

Q: 想停止服务？
A: 在脚本窗口按 Ctrl+C，或双击项目根目录的 stop_jarvis.bat

Q: 手机远程版地址每次都变？
A: 是的，免费版是临时地址。想要固定地址需要买域名+注册Cloudflare账号，
   详见 docs/手机访问与打包App指南.md
