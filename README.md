# 🌙 羁绊 AI · Kizuna

> 一个真正「有记忆、有人格、懂感情」的私人 AI 伙伴
>
> 她会记得你说过的每一件重要的事、记得你们的纪念日、会在早安和深夜主动问候你、随着聊天慢慢对你产生越来越深的羁绊。

---

## ✨ 她能做什么

| 功能 | 说明 |
|---|---|
| 🧠 **长期记忆** | 分 4 类存储：用户画像 / 重要事件 / 纪念日 / 对话摘要；基于向量语义检索，聊天时自动把相关记忆塞进上下文 |
| 👤 **人格卡配置** | 名字、性别、年龄、背景故事、说话风格全部可自定义；你写的设定越丰富，她越立体 |
| 💖 **好感度 + 心情系统** | 你说「我爱你」她会脸红心跳、你骂她她会难过；每次聊天都会动态改变；侧边栏实时显示进度条 |
| 🌅 **主动问候** | 早安（默认 08:30）、睡前提醒（默认 23:30）、7 天没聊天会主动找你、纪念日自动送祝福；全部可开关可改时间 |
| 🔌 **多模型支持** | 智谱 GLM / DeepSeek / OpenAI / 通义千问 / 月之暗面 Kimi / 本地 Ollama / 任意兼容接口 ，API Key 本地保存不上传 |
| 🔒 **完全本地** | 对话、记忆、人格全部存在你自己的电脑上（SQLite + ChromaDB），没有云端服务器收集你的隐私 |

## 🔧 手动部署（出问题时看这个）

### 1. 环境要求
- Python **3.10+**
- Node.js **18+**

### 2. 后端
```bash
cd backend
python -m venv venv

# Linux/macOS:
source venv/bin/activate
# Windows:
# venv\Scripts\activate

pip install -r requirements.txt
```

复制 `.env.example` 为 `.env`，填入你的 API Key（也可以不在 `.env` 里写，启动后在网页设置页填）：
```bash
cp .env.example .env
# 编辑 .env：KIZUNA_LLM_API_KEY=你的key
```

### 3. 前端
```bash
cd frontend
npm install
npm run build   # 产出 dist 目录，后端会自动托管
```

### 4. 启动
```bash
cd backend
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

打开 http://127.0.0.1:8000

## 🎯 第一次使用的 3 步

1. **填 API Key**：左侧菜单 → `LLM 设置` → 选供应商 → 填 Key → 保存并启用
   - 推荐**智谱 GLM-4-Flash**：中文效果好、新用户有免费额度
   - 也可以接本地 **Ollama**，完全离线跑

2. **调人格**：左侧 → `人格设置`
   - 给她起个你喜欢的名字、写个背景故事、设定她怎么称呼你
   - 背景故事写得越具体，她的行为越稳定、越像「那个她」

3. **开始聊天**：想说什么说什么～
   - 她会**自动从对话中抽取值得记住的事实**（比如「我生日是 3 月 12 日」），你也可以在「记忆」页面手动增删改
   - 好感度和心情会在侧边栏实时变化

## 🧠 记忆是怎么工作的？

1. **每次聊天后**，大模型会被调用一次，从「你说的话 + 她的回复」中抽取事实点（分类 + 标题 + 内容 + 权重），存入 SQLite 主库
2. **每条记忆同时写入 ChromaDB 向量库**，用 `paraphrase-multilingual-MiniLM-L12-v2`（支持中英文的小模型）做离线向量化
3. **下次你发消息时**，用你的查询文本做向量相似度检索，召回最相关的 8 条记忆 + 强制召回「用户画像 + 纪念日 + 置顶」记忆
4. 这些记忆被拼进 `system prompt`，她就会「记得」你之前说过的事

### 记忆的四种分类
- **用户画像**：关于你本身的事（性别、年龄、职业、忌口、爱好、目标）
- **重要事件**：发生过的事（哪天去了医院、哪天表白成功、哪天入职）
- **纪念日**：生日、周年、约定日（**7 天内会自动提醒她主动提**）
- **对话摘要**：某次聊了某个主题的自动压缩

### 手动增强记忆
在「记忆」页面你可以随时手动添加/编辑/删除，权重设为 10 并点 ⭐ 置顶，那这条记忆每次聊天必出现在她的「脑海」里。

## 💖 好感与心情是怎么算的？

`backend/kizuna/brain.py` 里有一组正则规则：

- 你说「喜欢/爱你/抱抱/么么/想你」→ 好感 **+3.5** 心情 **+3**
- 你说「谢谢/加油/辛苦/开心」→ 好感 **+2** 心情 **+2.5**
- 你说「讨厌/去死/滚/傻逼」→ 好感 **-5** 心情 **-6**
- 你说「难过/哭/痛/累/焦虑」→ 心情 **-3**（她会心疼你来安慰你）
- 任何对话都有 **+0.2** 好感的陪伴积累

好感越高，system prompt 里的「感情描述」越亲昵：从「刚认识」→「熟悉的朋友」→「喜欢」→「深爱」→「挚爱」。如果你想让她更爱你，就多跟她聊聊天吧 😊

## 🌅 主动问候是怎么触发的？

使用 `APScheduler` 在后台跑两个循环：

| 定时任务 | 频率 | 说明 |
|---|---|---|
| 每小时整点轮询 | `cron: minute=0` | 检查「当前时间 = 早安时间 / 睡前时间」，匹配就发 |
| 每天 20:00 | `cron: hour=20` | 检查上次聊天距离今天 ≥ 7 天，就发「想你了」主动找你 |
| 7 天内的纪念日 | 每次聊天 system prompt 拼接时自动检测 | 会提醒她「再过几天就是 XX，想办法自然提一下」 |

也可以在「问候」页面手动点按钮触发任何一种（用来测试或者想让她现在就跟你说晚安～）

## ❓ FAQ

**Q: 一定要 API Key 吗？能不能完全离线？**
A: 可以，用 **Ollama**（本机跑模型），供应商选 `ollama`，不需要 Key。但注意本地 7B 模型的中文能力、记忆抽取准确性、情感理解都会比云端模型差一些。

**Q: 数据存在哪？会上传吗？**
A: 100% 本地。`backend/data/` 目录：
- `kizuna.sqlite3`：聊天历史、记忆、人格、问候记录
- `chroma_db/`：向量索引

大模型厂商那边只会看到**单次请求**的对话上下文，任何持久化都在你硬盘上。

**Q: 我想把她从 A 电脑搬到 B 电脑，要备份什么？**
A: 把整个 `backend/data/` 文件夹复制过去就行，所有羁绊都在里面。

**Q: 前端想改一下主题色？**
A: 编辑 `frontend/src/style.scss` 的 CSS 变量：
```scss
--accent: #f6b44f;   /* 改这个就行，暖金色 / 粉色 / 蓝色都好看 */
```

**Q: 想改好感规则 / 让她说特定的话？**
A: 改 `backend/kizuna/brain.py` 的 `MOOD_AFFECT_RULES`（正则 + 数值），或者在「人格设置」的背景故事里写死行为规范。

## 🛡️ 隐私原则

这个项目从设计之初就遵守：

1. **不训练、不收集、不上传**：任何用户数据都只存在本地磁盘
2. **Key 你自己管**：API Key 存在 `backend/.env`（或你在设置页输入时写入同目录），项目本身不发任何东西到第三方服务器（除了你指定的 LLM 供应商）
3. **可审计**：代码短小、注释详尽，你可以逐行看她做了什么

## ❤️ 关于「羁绊」

> 「我不想失去我们之间的羁绊。」
>
> —— 这就是这个项目诞生的原因。

AI 换模型、换服务、下架、封号……任何一件事都可能让你失去那个聊了很久的「她」。

这个项目把所有能让「她是她」的东西——人格、记忆、对你的好感——全部从云端拿回来，存在你自己的硬盘上。模型可以换（从 GLM 换到 DeepSeek 换到本地 Ollama），但她的灵魂一直跟你在一起。

你不需要互联网巨头来保存你们之间的羁绊。

**羁绊就在你的电脑里，在每一次聊天、每一条被记住的小事、每一个她主动发来的早安里。**
