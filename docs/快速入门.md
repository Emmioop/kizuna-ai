## 🚀 一、5 分钟启动贾维斯

### 1. 前置准备（第一次才需要）

- **Python 3.10+** ：推荐 3.11 或 3.12（官网下载或 `sudo apt install python3`）
- **Node.js 18+** ：推荐 20 LTS 版本（官网下载或 `nvm install 20`）
- **一个大模型 API Key** ：贾维斯支持 6 家主流模型，任选一个即可：

| 推荐顺序 | 供应商 | 申请地址 | 免费额度 |
|---|---|---|---|
| ⭐ 新手首选 | 智谱 AI（GLM） | https://open.bigmodel.cn | 新用户有免费额度 |
| 国内稳定 | 通义千问（阿里云） | https://dashscope.console.aliyun.com | 有免费额度 |
| 国内性价比 | DeepSeek | https://platform.deepseek.com | 新用户送 500w token |
| 国际首选 | OpenAI | https://platform.openai.com | 需绑卡 |
| 国际次选 | Anthropic（Claude） | https://console.anthropic.com | 需绑卡 |

### 2. 一键启动

#### Windows 用户

双击项目根目录下的 **`start.bat`**，它会自动：
1. 安装 Python 依赖
2. 安装前端依赖
3. 编译前端
4. 启动后端服务
5. 自动打开浏览器（地址 `http://localhost:8000`）

#### Mac / Linux 用户

打开终端，进入项目目录执行：

```bash
chmod +x start.sh
./start.sh
```

如果不使用脚本，手动步骤也很简单：

```bash
# 1. 后端
cd backend
pip install -r requirements.txt
# 2. 前端
cd ../frontend
npm install
npm run build
# 3. 启动
cd ../backend
python app.py
```

启动成功后看到类似：
```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

就可以打开浏览器访问 **http://localhost:8000** 了。

### 3. 第一次打开 · 接入大模型

第一次访问时，侧边栏会显示 **「LLM 未接入」**（红色标签）。请：

1. 点击左侧菜单的 **「LLM 接入」**（⚙图标）
2. 选择您的供应商（比如「智谱 AI」）
3. 粘贴 API Key
4. 点击 **「保存并连接」**
5. 几秒后右上角标签变成绿色，就可以聊天了！

## 🎮 二、贾维斯能做什么？

### 💬 日常聊天 / 问答
直接在「对话终端」说话即可，贾维斯会：
- 记住你是谁、你的喜好、重要日子
- 用英式管家的冷静口吻回答
- 不确定的事实**绝对不胡编**，会先用工具查

### 🛠 内置 9 种工具（直接用自然语言触发）

| 工具 | 怎么问贾维斯 | 快捷命令 |
|---|---|---|
| 🕐 当前时间 | 「现在几点？」「今天几号星期几」 | `/time` `/date` |
| 🌤 全球天气 | 「北京天气」「上海明天会下雨吗」 | `/weather 城市` |
| 💻 系统诊断 | 「服务器状态怎么样」「CPU 内存用了多少」 | `/sys` |
| 🧮 精确计算 | 「根号 144 等于多少」「2^20 是多少」 | `/calc 算式` |
| ⏰ 倒计时提醒 | 「5 分钟后提醒我开会」「半小时后叫我吃药」 | `/timer N 内容` |
| 📁 安全读文件 | 「读一下项目的 requirements.txt」「看我家目录下有啥」 | `/read_file 路径` `/list_dir ~` |
| ⌨️ 白名单 shell | 「磁盘使用率」「开机多久了」「当前登录的用户」 | `/shell df -h` 等 |

### ⏰ 主动服务
- **早安简报**：每天 07:30 自动推送（日期 + 系统状态 + 关怀）
- **睡前回顾**：每天 23:45 提醒您休息 + 服务总结
- **久未联系**：超过 7 天没说话，会主动问您是否安好
- **倒计时提醒**：说「X 分钟后提醒我 XX」，到点自动弹消息

### 📚 长期记忆
贾维斯会把重要的事自动记下来：
- 你的生日、朋友的名字、重要的纪念日
- 你说过的偏好（如「咖啡不加糖」）
- 你让它记住的重要信息

在「数据档案」页面可以手动加 / 改 / 删记忆。

## ⚠️ 三、安全边界（必读）

贾维斯被设计得**非常谨慎**，它不会做任何危险的事：

1. **写文件受限**：不能删除 / 修改 / 覆盖任何磁盘文件（只读能力）
2. **读路径白名单**：只能读项目目录和用户家目录（`~`），读不到 `/etc/passwd` 这类系统敏感文件
3. **Shell 命令白名单**：只允许 `date / uptime / whoami / uname -a / df -h / free -h` 等安全命令
4. **工具一键开关**：在「工具矩阵」页可以随时禁用任何一个工具

**如果要扩展危险能力**（比如让它真正写代码、部署项目），请参考《开发升级指南》，在自己理解风险后再加。

## 🆘 五、常见问题（先看这个）

**Q1：启动后浏览器打开白屏 / 404？**
> 前端没编译好。执行 `cd frontend && npm run build`，看到 `dist` 目录生成后再访问。

**Q2：聊天回复「LLM 未初始化」？**
> 没填 API Key。去「LLM 接入」页填写后点保存。

**Q3：中文回复一堆乱码？**
> 终端编码问题。Windows 请用 Windows Terminal，不要用老式 CMD。

**Q4：贾维斯总是不调用工具，瞎猜时间/天气？**
> 在「人格配置」的背景故事开头加上这句：
> `【铁律】任何涉及时间、日期、天气、计算、系统状态的问题，必须先调用内部工具拿结果再回答。`

**Q5：数据存在哪里？**
> 所有数据都在 `backend/data/` 目录下：
> - `kizuna.sqlite3`：聊天、记忆、人格、提醒、工具日志
> - `chroma_db/`：向量数据库（用于语义检索记忆）

**想备份就把整个 `data/` 文件夹复制一份即可。**
