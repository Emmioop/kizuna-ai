## 🛠️ 二、最实用：加一个新工具（20 分钟学会）

这是你最常做的升级，比如加一个"查快递"、"翻译"、"发邮件"、"控制智能灯泡"的能力。

### 示例：加一个 `translate` 翻译工具

#### 步骤 1：在 `jarvis_tools.py` 里实现工具函数

找到文件末尾的 `build_registry()` 函数**之前**，加：

```python
# ---------- 10. 翻译（示例：对接免费 MyMemory API，不用 Key）----------
async def tool_translate(params: dict) -> ToolResult:
    text = (params.get("text") or "").strip()
    target_lang = (params.get("target_lang") or "zh-CN").strip() or "zh-CN"
    if not text:
        return ToolResult(False, "空文本", display="❌ 请告诉我要翻译的内容")
    # MyMemory 免费翻译 API（每天有限量，商用建议换 DeepL / 谷歌翻译）
    url = "https://api.mymemory.translated.net/get"
    try:
        import httpx
        async with httpx.AsyncClient(timeout=10) as c:
            r = await c.get(url, params={"q": text, "langpair": f"autodetect|{target_lang}"})
            data = r.json()
            translated = data["responseData"]["translatedText"]
            out = f"原文：{text}\n翻译（→{target_lang}）：{translated}"
            disp = (
                f"🌐 **翻译结果**（→ {target_lang}）\n"
                f"> 原文：{text}\n"
                f"> 译文：**{translated}**"
            )
            return ToolResult(True, out, display=disp)
    except Exception as e:
        return ToolResult(False, str(e), display=f"🌐 翻译失败：{e}")
```

#### 步骤 2：在 `build_registry()` 里注册这个工具

找到 `build_registry()` 函数的 `return r` **之前**，加：

```python
    r.register(ToolMeta(
        "translate",
        "翻译任意语种的文本。默认自动检测原文语种，默认翻译成中文（zh-CN）。要翻译成英文传 target_lang=en。",
        {
            "text": {"type": "string", "desc": "要翻译的文本，例如 Hello world", "required": True},
            "target_lang": {"type": "string", "desc": "目标语种代码：zh-CN=中文 / en=英文 / ja=日文 / ko=韩文 / fr=法文", "required": False},
        },
        ["把这句话翻译成英文：今天天气真好", "帮我翻一下这句日语", "翻成韩语"],
        category="info",
    ), tool_translate)
```

#### 步骤 3：重启贾维斯，测一下

1. 关掉后端 `Ctrl+C`，再 `python app.py`
2. 打开「工具矩阵」页面，你应该能看到新工具 `translate` 了
3. 点 ▶ 手动执行，随便填句话，看是否能正常出结果
4. 在聊天里直接说「帮我把 Hello world 翻译成中文」，看贾维斯能不能**自动选工具并调用**

#### 步骤 4（可选）：加快捷命令

在 `brain.py` 的 `chat()` 函数里找到快捷命令解析部分（`if cmd_match:` 那段），加一条：
```python
            elif tool_name == "translate":
                # /translate 你好世界 en → 翻译成英文
                parts = rest.rsplit(None, 1)
                if len(parts) == 2 and len(parts[1]) <= 6:
                    params["text"] = parts[0]
                    params["target_lang"] = parts[1]
                else:
                    params["text"] = rest
                    params["target_lang"] = "zh-CN"
```

这样用户就可以在对话框里用 `/translate 你好世界 en` 快速翻译了。

## 🧠 三、进阶：改贾维斯的"大脑"

### 3.1 改人格 / 说话风格（最简单，没风险）

**不用改代码！** 在网页「人格配置」页面就能改：
- `name`：AI 名称
- `nickname_for_user`：怎么称呼你
- `backstory`：这个是**核心人格 prompt**，它越长、描述越具体，贾维斯的性格越稳定
- `speech_style`：说话风格描述

### 3.2 改 System Prompt（让它做新的事情）

打开 `brain.py`，找到 `build_system_prompt()` 函数。
它返回给 LLM 的 system prompt = 人格部分 + 记忆部分 + 工具部分。

比如你想让贾维斯每次回答前都先**用一句话总结你上一条说的重点**，就直接在 `persona_part` 的末尾【核心守则】里加：

```
6. 回答用户前，先用方括号 [📝 你的意思是：……] 简要复述一次用户的核心需求，确认没理解错，然后再给正式回答。
```

### 3.3 改情绪 / 信任规则

在 `brain.py` 的最上面有 `TRUST_AFFECT_RULES` 列表，每行是一个 `(正则, 信任变化, 稳定度变化)`：

```python
TRUST_AFFECT_RULES = [
    (re.compile(r"(谢谢|感谢)"), +2.5, +1.5),
    # 你可以加自己的规则，比如：
    (re.compile(r"(我爱你|最喜欢贾维斯)"), +5.0, +3.0),
    (re.compile(r"(滚|去死|闭嘴)"), -5.0, -4.0),
]
```

### 3.4 加一种新的"主动行为"（比如：每个整点报时）

在 `app.py` 的 `lifespan()` 函数里找到 APScheduler 部分，加一个新的定时任务：

```python
        # 每个整点报时
        async def every_hour_report():
            sess = _SESSION_FACTORY()
            try:
                if _BRAIN:
                    now = datetime.now()
                    # 写一条 assistant 消息
                    from .db import Message, Persona
                    from sqlalchemy import select
                    content = f"先生，现在是 {now.strftime('%H:00')}。一切系统运行正常。"
                    msg = Message(role="assistant", content=content)
                    sess.add(msg)
                    # 更新 persona 计数
                    p = (await sess.execute(select(Persona).order_by(Persona.id.asc()))).scalars().first()
                    if p:
                        p.total_chats += 1
                        p.last_chat_at = datetime.now()
                    await sess.commit()
            finally:
                await sess.close()

        sched.add_job(every_hour_report, "cron", minute=0, id="every_hour_report")
```

这样每到整点，贾维斯就会主动在对话里弹一句话告诉你时间。

## 🗃️ 四、加新的数据表（更进阶）

比如你想加一个"**待办清单 (Todo)**"功能，让贾维斯记住你要做的事。

### 步骤 1：在 `db.py` 里定义表

```python
class Todo(Base):
    __tablename__ = "todos"
    id = Column(Integer, primary_key=True)
    content = Column(String(500), nullable=False)       # 待办内容
    priority = Column(Integer, default=3)               # 1~5 优先级
    done = Column(Boolean, default=False)               # 是否已完成
    due_time = Column(DateTime, nullable=True)          # 截止时间
    created_at = Column(DateTime, default=datetime.now)
```

### 步骤 2：在 `app.py` 里加 API（增删改查）

比如 `@app.post("/api/todos")`、`@app.get("/api/todos")` …… 写法跟 `memory` 的 API 一模一样，照着抄即可。

### 步骤 3：在 `jarvis_tools.py` 里加 3 个工具

- `todo_add`：加一个待办
- `todo_list`：列出今天的待办
- `todo_done`：标记某个待办完成

### 步骤 4：前端加一个 Todo.vue 页面

照着 `Memory.vue` 的结构写，然后在 `main.js` 里加路由。

## 🤖 五、接入新的大模型供应商

打开 `llm.py`，你会看到 `SUPPORTED_PROVIDERS` 和每个 provider 的 config。

只要你的新模型**兼容 OpenAI API 协议**（现在基本都兼容），直接在 `SUPPORTED_PROVIDERS` 里加一条就行，比如接入 Groq：

```python
SUPPORTED_PROVIDERS = {
    # ... 现有 6 家
    "groq": {
        "label": "Groq（Llama 3）",
        "base": "https://api.groq.com/openai/v1",
        "default_model": "llama3-70b-8192",
        "docs": "https://console.groq.com/keys",
    },
}
```

然后在 Settings.vue 的供应商下拉里就会出现。**一般不用改一行适配代码！**

如果不兼容 OpenAI 协议，就在 `ChatLLM._openai_like()` 旁边抄一个新方法，比如 `_anthropic()`，然后在 `complete()` 的 if-elif 分支里加上。

## 🎨 六、改前端主题 / UI

### 6.1 改配色（最容易）

打开 `style.scss`，最上面的 `:root` 里就是所有颜色变量：

```scss
:root {
  --bg: #02060c;          /* 背景：想换成暗夜紫？改成 #0a0210 */
  --accent: #3fd5ff;      /* 主强调色：贾维斯青 → 想换成钢铁侠红？改成 #e63946 */
  --accent-2: #1e90ff;    /* 次要蓝 */
  --accent-3: #00ffaa;    /* OK 绿 */
  --accent-warn: #ffca3a;  /* 警告黄 */
  --accent-danger: #ff4757;/* 危险红 */
}
```

只改这几个变量，整个 UI 就换色了，不用改别的地方。

### 6.2 新增一个页面

1. 复制 `views/Memory.vue` 作为模板，重命名为 `views/YourPage.vue`
2. 在 `main.js` 里 import 它，并在 `routes` 数组里加一条
3. 在 `App.vue` 侧边栏 `<nav>` 里加一条 `<router-link>`

### 6.3 彻底换 UI 风格

贾维斯当前是 **HUD 风格**（深蓝+扫描线+电弧反应堆），如果你想换成：
- **Friday 风格**（偏粉紫）：改配色 + 把电弧反应堆换个色
- **钢铁侠 3 马克 42 风格**（金红）：--bg 改成深黑，--accent 改金色，--accent-danger 改装甲红
- **极简白**：--bg 改白，--text 改黑，注释掉 `body::before` 的扫描线

## 💡 八、10 个升级灵感（可以慢慢实现）

1. **🔊 语音播报**：接入 edge-tts，贾维斯回复后自动朗读（后端加个语音生成 API + 前端 `<audio>` 播放）
2. **📧 邮件助手**：加 `send_email` 工具，用 SMTP 发邮件
3. **🏠 智能家居控制**：接 Home Assistant API，让贾维斯开关灯/空调（加工具）
4. **📱 Telegram / 飞书机器人**：把 FastAPI 的 chat 接口接到机器人 SDK，在手机上也能用
5. **📊 每日总结**：每天 23:00 自动把今天的聊天内容抽成 3 句摘要，存在记忆里
6. **🌙 多人格切换**：存多套 Persona，可一键切贾维斯 / 星期五 / 伊迪斯
7. **🧩 插件系统**：把工具做成 `plugins/` 目录下的独立 py 文件，启动时自动 import 注册
